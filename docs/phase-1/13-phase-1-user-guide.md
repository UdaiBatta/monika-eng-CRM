# Phase 1 User Guide

This guide covers the shared foundation. Your available buttons and menu items depend on your job permissions.

## Upload a document

Open **Documents**, choose **Upload document**, select a file and category, and enter a clear title. The screen tells you which file types and size are allowed. Choose **Upload**. If the file is rejected, follow the plain-language message; changing a filename does not change an unsafe file type.

## Download a document

Open the document and choose **Download**. You must be signed in and authorized each time. Do not expect or share a public file link.

## Add a newer version

Open an active document and choose **Add new version**. Select the updated file and describe what changed. Earlier versions remain in **Version history** and can still be downloaded by authorized employees.

## Submit a document for approval

Open the document, choose **Submit for approval**, select an active approval workflow and add a helpful message. The current document is attached as supporting information. If no workflow appears, ask an administrator to configure and activate the correct route.

## View activity history

Open **Activity History**. Search or filter for the area, action, employee or record. Select an activity to see what happened, who did it, when it happened and readable **Before**/**After** values where applicable.

## Approve a request

Open **My approvals** and select **Needs my action**. Review the record, supporting files and earlier steps. Choose **Approve**, check the confirmation and add a useful comment if needed. Your decision is permanent.

## Return a request for changes

Choose **Return for changes**, explain exactly what the requester should correct, then confirm. A comment is required.

## Reject a request

Choose **Reject**, enter the business reason and confirm. Reject only when the record should not continue through this approval request.

## Read notifications

Use the bell in the top bar. The number shows unread items. Select a notification to mark it read and open the related ERP page. Use **Mark all read** when you have reviewed the list.

## What “Access restricted” means

The record exists, but your current job permissions do not allow this screen or action. It does not mean the data is lost. Ask your manager or ERP administrator to review your role; do not ask another employee to share a private downloaded file as a workaround.
